# СТО MaxCar — сайт (landing)

Чистый HTML/CSS/JS, без фреймворков и сторонних библиотек.

## Запуск

Просто откройте `index.html` в браузере, либо поднимите любой статический сервер:

```bash
npx serve .
# или
python3 -m http.server 8080
```

## Структура

```
index.html          ← вся разметка страницы, один лендинг
css/styles.css       ← все стили, mobile-first, дизайн-токены в :root
js/script.js          ← список услуг, мобильное меню, карусель, статус "открыто/закрыто"
assets/images/        ← все изображения сайта лежат локально (SVG-иллюстрации)
```

## Что нужно заменить перед публикацией

1. **Изображения** — в `assets/images/` сейчас иллюстрации-заглушки
   (hero-illustration.svg и gallery-1…5.svg), стилизованные схематичные рисунки,
   а не фотографии реального СТО или реальных автомобилей клиентов. Замените их
   на настоящие фотографии сервиса и работ, когда они будут готовы — просто
   положите файлы с теми же именами в эту папку (или обновите пути в
   `index.html` / `js/script.js`).
2. **Telegram-ссылка** — сейчас используется `https://t.me/+380505050024` и
   `viber://chat?number=%2B380505050024` на основе указанного номера телефона.
   Если у СТО есть отдельный юзернейм в Telegram — замените ссылку на него.
3. **Карта** — встроена по названию адреса. Для точного маркера рекомендуется
   получить embed-код конкретной точки в Google Business Profile.
4. **Список услуг** — редактируется в `js/script.js`, массив `SERVICES` в самом
   начале файла.

## Заметка о данных

Адрес, телефон, график работы (08:30–19:00 ежедневно) и список услуг взяты
дословно из предоставленного брифа. Цены, гарантии, сроки ремонта и
дополнительные контакты не указаны, так как их не было в исходных данных.

Статус «Открыто сейчас / Сейчас закрыто» в шапке считается на лету в браузере
по текущему времени пользователя и указанному графику (08:30–19:00 ежедневно).
